wecom-channel-cli

Read and watch WeCom channels; propose reviewed replies through an isolated broker

Usage:
  wecom-channel-cli [flags]
  wecom-channel-cli [command]

Available Commands:
  approval    Operator-only review and execution; requires the private operator socket
  auth        Explain credential ownership and verify through the broker
  broker      Run the isolated credential-holding broker
  channel     Inspect channel data through broker policy
  config      Inspect operator policy offline
  doctor      Check broker connectivity and read-only policy
  event       Read or watch authenticated channel events
  member      Inspect member data through broker policy
  post        Inspect post data through broker policy
  proposal    Inspect immutable proposal status
  reply       Inspect reply data through broker policy
  search      Inspect search data through broker policy
  skill       Inspect or install the embedded companion Skill
  version     Print build metadata

Flags:
      --allow-writes         Override only WECOM_CHANNEL_CLI_READ_ONLY; never broker policy or approval
      --config-dir string    Client context directory (or WECOM_CHANNEL_CONFIG)
      --format string        Output format: json or ndjson; trust metadata is always retained (default "json")
      --socket string        Unix socket path (or WECOM_CHANNEL_SOCKET)
      --timeout duration     Bound the entire local request (default 1m5s)
      --use-context string   Select a channel security context (or WECOM_CHANNEL_CONTEXT)

Use "wecom-channel-cli [command] --help" for more information about a command.

wecom-channel-cli event watch

Watch a whole channel or selected post threads as bounded NDJSON

Usage:
  wecom-channel-cli event watch [flags]

Examples:
  wecom-channel-cli --use-context engineering event watch --whole-channel --duration 10m
  wecom-channel-cli --use-context engineering event watch --post POST_ID --checkpoint .watch/thread.json --duration 10m

Flags:
      --after-sequence int   Replay after this sequence instead of starting at the current head
      --allow-partial        Explicitly accept an inbox restricted to allowlisted human authors
      --checkpoint string    Optional private resume file in an existing agent-owned directory
      --dry-run              Inspect scope and coverage without streaming or saving a checkpoint
      --duration duration    Maximum total watch duration, up to 24h (default 5m0s)
      --interval duration    Delay between bounded inbox requests, 1s–1m (default 2s)
      --max-events int       Stop after this many matching emitted events (default 1000)
      --post stringArray     Watch this post and its replies; repeat for up to 32 post IDs
      --whole-channel        Watch post/reply changes throughout this channel context

Global Flags:
      --allow-writes         Override only WECOM_CHANNEL_CLI_READ_ONLY; never broker policy or approval
      --config-dir string    Client context directory (or WECOM_CHANNEL_CONFIG)

  wecom-channel-cli post propose [flags]

Flags:
      --channel string   Exact channel ID
      --dry-run          Preview the exact proposal without storing or sending it
      --key string       Stable caller-chosen idempotency key; reuse it after a transport failure
      --stdin            Read the exact content from stdin; no file is opened by the broker
      --text string      Exact text to propose; use --stdin to avoid shell quoting and argv exposure

Global Flags:
      --allow-writes         Override only WECOM_CHANNEL_CLI_READ_ONLY; never broker policy or approval
      --config-dir string    Client context directory (or WECOM_CHANNEL_CONFIG)
      --format string        Output format: json or ndjson; trust metadata is always retained (default "json")
      --socket string        Unix socket path (or WECOM_CHANNEL_SOCKET)
      --timeout duration     Bound the entire local request (default 1m5s)
      --use-context string   Select a channel security context (or WECOM_CHANNEL_CONTEXT)
